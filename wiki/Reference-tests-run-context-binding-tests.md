# tests/run-context-binding-tests.sh

**Classification:** INTERNAL TEST TOOLING. Compiles `tests/ContextBindingTests.cpp` against the exact sibling System, Platform, Clock, Memory, BoundedTopology and Portable headers, then runs ordinary and exceptional-exit subprocess forms. The portable/native binding fixtures are test-only and make no SDK/hardware claim.

No positional arguments. `CXX` selects a compiler executable; `EDP_THREADING_TEST_OPTIMIZATION` selects one compiler optimization flag (default -O0); `EDP_THREADING_SANITIZERS=1` adds address/undefined checking. ROOT and WORKSPACE resolve coherent sibling source. OUTPUT is a unique temporary executable removed by the EXIT trap. The includes/flags arrays preserve separate arguments; all builds use C++20, strict warnings and pthreads. `set -euo pipefail` and timeout propagate failures. ASAN_OPTIONS/UBSAN_OPTIONS request immediate failure; leak detection is disabled for the separate deliberate retained-owner fixture. Each subprocess has a 30-second test limit, independent of production Clock budget semantics. The corresponding context-binding workflow covers both compilers/optimizations; authoritative execution evidence resides in Policy handoffs.
