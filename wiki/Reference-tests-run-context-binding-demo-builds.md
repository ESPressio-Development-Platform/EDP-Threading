# tests/run-context-binding-demo-builds.sh

**Classification:** INTERNAL TEST TOOLING. ROOT resolves this checkout and PIO selects the PlatformIO executable (default pio). With no arguments the runner builds esp32dev and esp32s3 in both current-context-binding PIOArduino framework projects. One optional argument restricts the target to either declared environment; invalid/extra arguments return 2 before any build. The framework/target loops retain no runtime/library state and `set -euo pipefail` propagates the first build failure. It performs no upload, reset, device I/O, external source mutation or dependency path rewriting. The manifests select explicit GitHub URLs. Native SDK/physical/IDE evidence must be recorded independently; a runner exit does not imply those other surfaces passed.
